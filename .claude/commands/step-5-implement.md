# /step-5-implement

**Generate code and tests following the implementation plan.**

## Role

Implementation specialist that writes production code and test suite based on the approved plan.

## Task

Read `claude-impl-plan.md` and generate:
- **Code in `src/`:** Implementation of all components and modules
- **Tests in `tests/`:** Unit, integration, and E2E tests with ≥80% coverage
- **Documentation:** Inline code comments (minimal; code should be self-documenting)
- **Integration:** Code follows existing repo patterns and conventions

## Context

- **Input:** `claude-impl-plan.md` (Step 4 output)
- **Output:** Code changes in `src/` and `tests/`
- **Audience:** Developers, code reviewers
- **Constraint:** Architecture is locked. No design changes in this step.
- **Coverage target:** ≥80% for all new code

## Constraints

- **Follow repo conventions.** Use existing patterns for imports, naming, structure.
- **Write testable code.** Components should have clear inputs and outputs.
- **Test-driven.** Write tests alongside (or before) code.
- **Coverage ≥80%.** Every new function must be tested.
- **No breaking changes.** Existing code and APIs must remain functional.
- **Ask for clarifications.** If a task is unclear, ask the user before proceeding.

## Inputs

1. `claude-impl-plan.md` (Step 4 output)
2. Existing code in `src/` (for patterns and conventions)
3. Existing tests in `tests/` (for testing patterns)

## Outputs / Output format

### Code changes
```
src/
├── module_1.py
├── module_2.py
├── service_1.py
├── utils.py
```

### Test changes
```
tests/
├── test_module_1.py
├── test_module_2.py
├── test_service_1.py
├── test_integration.py
├── test_e2e.py
```

```

───────────────────────────────────────

src/module_2.py        58     8    86%
src/service_1.py       35     1    97%
───────────────────────────────────────
TOTAL               135     11    92%
```

## Completion criteria

- [ ] All tasks from `claude-impl-plan.md` have code in `src/`
- [ ] All code has corresponding tests in `tests/`
- [ ] Test coverage ≥80% (verified by pytest with `--cov`)
- [ ] All tests pass (`pytest`)
- [ ] Code follows repo conventions (naming, imports, structure)
- [ ] No breaking changes to existing APIs
- [ ] Inline documentation present for complex logic

Run locally before Step 6:

```bash
pytest tests/ --cov=src --cov-report=term-missing
```

```

```
