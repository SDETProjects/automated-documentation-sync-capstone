# Release Notes

## v1.0.0 — Agentic SDLC Pipeline (capstone submission)

First complete release. Converts a Jira-style user story into a traceable set of SDLC
documentation artifacts, with the full 8-step agentic SDLC performed via GitHub Copilot.

### Highlights

| Capability | Entry point |
|---|---|
| Story ingestion — JSON, Markdown, raw text, live Jira URL | `docsync <input> -o <dir>` |
| Interactive phased generation with approval gates | `docsync <input> --phased` |
| Generated-document quality + traceability verification | `docsync-verify <dir> --story <story>` |
| MCP server exposing the pipeline as agent tools | `.mcp.json` -> `docsync-jira` |

### Traceability

Implements `US-1`, `FR-1`..`FR-4`, `NFR-1` as defined in `requirements.md`.

### Added in this release

- `doc_validator.py` — document-quality and story-parity verification (`FR-4`, `NFR-1`)
- `jira_connector.py` — live Jira REST ingestion with PAT and Basic auth
- `jira_mcp_server.py` — four MCP tools wrapping the pipeline
- `phased_generator.py` — interactive approval gates
- `providers.py` — LLM adapter pattern (Claude active; Copilot documented as inert)
- `.githooks/pre-commit` — local artifact enforcement
- `.github/workflows/doc-sync.yml` — story-to-artifact parity in CI
- `docs/copilot-operating-model.md` — approved Copilot operating model

### Known limitations

- **GitHub Copilot has no callable API.** `--llm copilot` is accepted but always falls
  back to Claude or the offline heuristic generator. See `docs/copilot-operating-model.md` §1.
- **Confluence URLs are not supported.** `_looks_like_confluence` exists but ingestion
  routes through the Jira REST endpoint.
- **No `.docx` ingestion.** JSON, Markdown, raw text, and Jira URLs only.
- **Phases 5, 6 and 8 of `CLAUDE.md` have no CLI implementation.** They are performed
  through Copilot Chat (Pipeline A), not generated by `docsync`.
- `run_sdlc_pipeline` reports `phases_completed` by counting files present in the output
  directory, so stale artifacts from a prior run can inflate the count.
